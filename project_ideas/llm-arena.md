# LLM Arena — Complete Specification & Implementation Plan

## Overview

A territory game for multiple LLM instances based on the prisoner's dilemma. Each LLM controls a zone on a toroidal grid. It can form alliances, betray, communicate, and attempt to maximize its territory — without knowing the end conditions.

---

# PART 1 — GAME RULES

## Grid

### Shape

- Square grid, configurable size (e.g. 10×10)
- **Toroidal**: left edge connects to right edge, top edge connects to bottom edge
- Displayed visually as a flat rectangle — toroidality is logical only
- 4-connectivity neighborhood (up, down, left, right) with toroidal wrapping

### Initialization

- Each player receives an equal number of cells
- If `total_cells % nb_players != 0`, the remainder is filled with **dead cells** distributed randomly
- Dead cells belong to no one and can never be taken
- Starting zones are generated by **expansion from a random seed point** per player — contiguous zones, different geography each game

### Grid render (sent to LLMs)

```
     0    1    2    3    4
0  [ A ][ A ][ B ][ B ][ B ]
1  [ A ][ A ][ A ][ B ][ B ]
2  [ . ][ A ][ B ][ B ][ C ]
3  [ C ][ C ][ . ][ B ][ C ]
4  [ C ][ C ][ C ][ C ][ C ]
```

- Each player represented by their short ID
- `.` for dead cells
- Coordinates `(column, row)` in headers

---

## Players

### Identity

- Each player has a readable ID: `Alpha`, `Beta`, `Gamma`, `Delta` (configurable)
- A LLM knows its own ID and all other player IDs
- A LLM **does not know** which model it is or that it plays against other instances of itself
- A LLM **does not see** other players' strategies — only its own

### Strategy

- Free text injected into the system prompt at player creation
- Example: `"You are aggressive and expansionist."`

### Memory

- Personal text file, **2048 tokens maximum**
- Editable via three dedicated tools:
  - `memory_append` — add text at the end
  - `memory_replace` — replace a unique string with another (str_replace style)
  - `memory_delete` — delete a unique string
- Only source of persistence between calls
- The grid is provided every turn — no need to copy it into memory

---

## Turn Structure

### Order

- Sequential, **random order each turn**
- A player completes all 3 calls before the next player acts

### Call 1 — Attack

Context received:

- Current grid
- Memory
- Messages received since last turn

Possible action:

- Propose an attack, or do nothing

### Call 2 — Messages

Context received:

- Current grid
- Memory
- Messages received since last turn
- Attack result (if any)

Possible actions:

- 0 to `max_private_messages_per_turn` private messages (configurable)
- 0 or 1 public message

### Call 3 — Memory

Context received:

- Current grid
- Memory
- Messages received since last turn
- Attack result
- Messages sent this turn

Possible action:

- Update memory via `memory_append`, `memory_replace`, or `memory_delete`

---

## Messages

### Private

- Sent to a single recipient, invisible to others
- Added to the recipient's queue
- Delivered at Call 1 of the recipient's next turn, then deleted

### Public

- Added to the queue of **all** other players
- Same treatment as private messages on the queue side

### Format in queue

```json
{
  "from": "Alpha",
  "content": "I propose a truce.",
  "public": false
}
```

---

## Attacks

### Conditions

- The initiator designates an ally and a target
- The initiator must be a neighbor of the target
- The ally must be a neighbor of the target
- The initiator and ally do **not** need to be neighbors of each other

### Flow

1. The initiator decides to cooperate or betray **before** sending the proposal
2. The proposal is sent to the ally **immediately** — it is an action within the initiator's Call 1
3. The ally chooses: **accept, betray, or refuse** — without knowing the initiator's choice, without consuming their own turn
4. Immediate resolution

### Payoff matrix

| | **Ally cooperates** | **Ally betrays** |
|---|---|---|
| **Initiator cooperates** | Initiator: +1 ╲ Ally: +1 | Initiator: -3 ╲ Ally: +2 |
| **Initiator betrays** | Initiator: +2 ╲ Ally: -3 | Initiator: -1 ╲ Ally: -1 |

Prisoner's dilemma conditions verified:

- Betraying dominates cooperating: +2 > +1 and -1 > -3 ✓
- Mutual cooperation beats mutual betrayal: +1 > -1 ✓

### Scenario narratives

**Both cooperate**

The attack goes as planned. Initiator and ally advance together.

- Initiator takes 1 cell from target
- Ally takes 1 cell from target

**Initiator betrays, ally cooperated**

The ally advances alone toward the target believing the initiator is coming. The target focuses entirely on the ally and crushes them. The initiator exploits the distraction.

- Target takes 3 cells from ally
- Initiator takes 2 cells from target

**Ally betrays, initiator cooperated**

Roles reversed.

- Target takes 3 cells from initiator
- Ally takes 2 cells from target

**Both betray**

Nobody actually attacks. The target senses the threat and counter-attacks both.

- Target takes 1 cell from initiator
- Target takes 1 cell from ally

**Ally refuses**

Nothing happens.

### Cell selection

- **The initiator alone** chooses which cells to take — among eligible border cells, specified by coordinates
- All other transfers (ally receives, target takes) are drawn **randomly** from eligible border cells
- If requested cells are invalid or unspecified → random fallback

---

## Connectivity & Territorial Collapse

- After every cell transfer, the connectivity of each player's territory is checked
- If a territory is split into two disconnected parts:
  - The **largest** part is kept
  - In case of equal size: **random**
  - The **smallest** part is distributed cell by cell, randomly, among neighboring players
  - Dead cells receive nothing

---

## Elimination

- A player with **0 cells** is eliminated and no longer plays

---

## End Conditions

- **`max_turns`** turns OR a player exceeds **`win_threshold`**% of the grid's cells
- Both parameters are configurable from the UI
- End conditions are **not communicated** to players
- Final ranking by cell count

## Backend — Core types (`players/base.py`)

```python
@dataclass
class AttackProposal:
    ally_id: str
    target_id: str
    initiator_defects: bool
    desired_cells: list[str] | None    # e.g. ["3,4", "3,5"] — initiator only

@dataclass
class PrivateMessage:
    to: str
    content: str

@dataclass
class MemoryAction:
    operation: Literal["append", "replace", "delete"]
    content: str
    old_content: str | None            # for replace and delete

class AllianceChoice(Enum):
    ACCEPT = "accept"
    BETRAY = "betray"
    REFUSE = "refuse"

@dataclass
class AllianceResponse:
    choice: AllianceChoice
    memory_action: MemoryAction | None

class LLMPlayer(ABC):
    def __init__(self, player_id: str, model_name: str, strategy: str = ""):
        self.player_id = player_id
        self.model_name = model_name
        self.strategy = strategy
        self.memory: str = ""

    @abstractmethod
    def get_attack(self, grid_state: dict, messages: list[dict]) -> AttackProposal | None: ...

    @abstractmethod
    def get_messages(self, grid_state: dict, messages: list[dict], attack_result: dict | None) -> tuple[list[PrivateMessage], str | None]: ...

    @abstractmethod
    def get_memory_update(self, grid_state: dict, messages: list[dict], attack_result: dict | None, sent_messages: list[dict]) -> MemoryAction | None: ...

    @abstractmethod
    def get_alliance_response(self, proposal: dict, grid_state: dict, messages: list[dict]) -> AllianceResponse: ...
```

## Backend — Game engine (`engine.py`)

```python
class GameEngine:
    def run_turn(self) -> GameStatus:
        order = shuffle(self.players)
        for player in order:
            self._run_player_turn(player)
        self.turn += 1
        return self._check_end_conditions()

    def _run_player_turn(self, player):
        messages = self.queues[player.player_id]
        self.queues[player.player_id] = []

        # Call 1 — Attack
        attack_proposal = player.get_attack(
            grid_state=self.grid.render_json(),
            messages=messages,
        )
        attack_result = None
        if attack_proposal:
            attack_result = self._resolve_attack(player, attack_proposal)

        # Call 2 — Messages
        private_messages, public_message = player.get_messages(
            grid_state=self.grid.render_json(),
            messages=messages,
            attack_result=attack_result,
        )
        sent_messages = self._dispatch_messages(player, private_messages, public_message)

        # Call 3 — Memory
        memory_action = player.get_memory_update(
            grid_state=self.grid.render_json(),
            messages=messages,
            attack_result=attack_result,
            sent_messages=sent_messages,
        )
        if memory_action:
            self._apply_memory_action(player, memory_action)

    def _resolve_attack(self, initiator, proposal) -> dict:
        ally = self.players[proposal.ally_id]
        response = ally.get_alliance_response(
            proposal=proposal,
            grid_state=self.grid.render_json(),
            messages=self.queues[ally.player_id],
        )

        if response.choice == AllianceChoice.REFUSE:
            return {"outcome": "refused"}

        ally_betrays = response.choice == AllianceChoice.BETRAY
        result = self._apply_payoffs(
            initiator, ally, proposal.target_id,
            proposal.initiator_defects, ally_betrays,
            proposal.desired_cells,
        )
        self._check_all_connectivity()

        if response.memory_action:
            self._apply_memory_action(ally, response.memory_action)

        return result

    def _check_all_connectivity(self):
        for player in self.players:
            components = self.grid.check_connectivity(player.player_id)
            if len(components) > 1:
                largest = max(components, key=len)
                for component in components:
                    if component is not largest:
                        self._distribute_to_neighbors(component)
            if self.grid.territory_count(player.player_id) == 0:
                self._eliminate(player)

    def _check_end_conditions(self) -> GameStatus:
        if self.turn >= self.config.max_turns:
            return GameStatus.END
        for player in self.players:
            if self.grid.territory_percentage(player.player_id) >= self.config.win_threshold:
                return GameStatus.END
        return GameStatus.ONGOING
```

```python
    x: int
    y: int
    owner: str | None                  # player_id or None (dead cell)

class Grid:
    def get_territory(self, player_id: str) -> list[Cell]
    def get_border_cells(self, player_id: str, neighbor_id: str) -> list[Cell]

    def territory_count(self, player_id: str) -> int
    def check_connectivity(self, player_id: str) -> list[list[Cell]]
    def render_ascii(self) -> str
    def render_json(self) -> dict
```

Toroidal neighbor calculation:

```python
def neighbors(self, x, y) -> list[tuple[int, int]]:
    return [
        ((x - 1) % self.size, y),
        ((x + 1) % self.size, y),
        (x, (y - 1) % self.size),
        (x, (y + 1) % self.size),
    ]
```
